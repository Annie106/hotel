# 网页建模独栋别墅 · 测试项目

这个是WorkBuddy的hy4模型制作的网页建模独栋别墅的测试项目。

## 项目文件

| 文件 | 说明 |
| --- | --- |
| `hotel/index.html` | 3D 别墅页面入口与控制面板 |
| `hotel/app.js` | 场景建模、家具、夕阳光影与交互逻辑 |
| `hotel/vendor/three.global.js` | 本地离线 Three.js r160 |

## 打开方式

直接用浏览器打开 `hotel/index.html` 即可，无需联网、无需启动服务。

页面支持鼠标 / 触屏旋转缩放、镜头视角切换、楼层剖切，以及 16:00–20:00 的日照时间轴。
